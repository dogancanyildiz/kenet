# Toplantı Notları

Haftalık senkronizasyon toplantılarından alınan teknik notlar.

## Örnek Format ve Şablon

Aşağıdaki blok ayrıştırıcı testlerinde kod bloğunun yutulmasını denetlemek içindir:

```markdown
## Events
- 10:00 [[Deniz Arıkan]] ile planlama ^hbrpoi
```

## Değerlendirme

Toplantı çıktılarını [[Liman Ofis]] panosuna ekleyeceğiz.
